# 信源核验与学术溯源铁律规范 (Research Verification Standards)

> **原则**：严谨可审计、零胡编乱造 (No-Fabrication)、零不可控链接。
> 所有进入调研报告的信息必须具备**独立的第三方可核验凭证**。
>
> **核心立场**：可审计性不是靠"要求模型别幻觉"实现的，而是靠**核验回路**。
> 本文件定义"什么算核验通过"；`scripts/verify.py` 负责自动执行。

---

## 0. 核验方式分级（每条事实必须标注其一）

| 核验方式 | 含义 | 可信度 |
| :--- | :--- | :--- |
| `DOI 反查` | 通过 CrossRef API 反查，标题/作者/卷期页与文中逐项一致 | 最高 |
| `PMID 反查` | 通过 NCBI E-utilities 反查，同上 | 最高 |
| `出版社页面` | 出版社官方专页可直接打开并显示该著作 | 高 |
| `官方页面` | 目标机构官网页面可直接打开并载有该信息 | 高 |
| `HTTP 实测` | 链接返回 200，但页面内容未逐字比对 | 中 |
| `反爬待人工` | 链接返回 403/429，脚本无法判定，**必须人工点击确认** | 待定 |
| `未核验` | 无任何凭证 | **禁止写入正文** |

> ⚠️ **禁止在未跑通 `verify.py` 的情况下使用"所有文献均经核验"这类表述。**
> 这是一句关于证据状态的事实断言，没跑过就是编的。

---

## 1. 学术文献链接硬性约束

> [!CAUTION]
> **绝对禁止使用 Google Scholar 动态搜索链接**（形如 `https://scholar.google.com/scholar?q=...`）。
> 此类动态查询会频繁触发 Google 反爬风控拦截（`We're sorry... automated queries`），导致审核失败。

> [!CAUTION]
> **禁止把 ResearchGate、Academia.edu、Semantic Scholar 等第三方转载页当作"永久直链"。**
> 理由有二：
> 1. 它们同样是**动态页**，同样会被反爬拦截——用它们规避 Google Scholar 的风控问题，逻辑上并不成立；
> 2. 它们不是**一手来源**，存在版本与元数据失真的可能。
>
> 只有在确实找不到任何一手来源（DOI / 出版社 / 官方档案）时，才可降级使用，
> 且必须在「核验方式」列标注为 `第三方转载`。

### 必须使用的永久有效学术直链：

1. **DOI 永久解析链接**：
   - 格式：`https://doi.org/[DOI_IDENTIFIER]`
   - 适用：所有在期刊、会议正式出版的同行评议论文。
2. **国家级/官方学术数据库收录页**：
   - 医学与生物学：PubMed（`https://pubmed.ncbi.nlm.nih.gov/[PMID]/`）或 PMC。
   - 物理与工程：DOE OSTI（`https://www.osti.gov/biblio/...`）或 arXiv 永久页面（`https://arxiv.org/abs/...`）。
3. **机构论文库与会议永久档案库**：
   - 优先使用带 handle 的机构库（`https://hdl.handle.net/...`），而非第三方镜像。
4. **出版社官方图书与论文专页**：
   - Taylor & Francis、Springer、Wiley、Oxford、Cambridge、Brill 等官网作品详情页。
   - **专著优先链接出版社专页，而非作者个人主页**——个人域名会失效、会被转手。

### 卷期页码必须来自 API，不得凭印象填写

引用文献时必须给出准确的**卷、期、页码**，且该数据必须来自 CrossRef / PubMed 的反查结果。

- 论文可能先在线发表（较早年份）后编入纸本某一期（较晚年份），两处年份不同属正常，
  **但卷、期、页码在正式编期后是唯一的**。
- 凭记忆或"看起来合理"填写卷期页，即使论文真实存在，也构成**事实性编造**。

## 2. 招生政策与小文书 Prompt 审计规范

1. **必须给出官方页面深链**：指向**实际显示该题目的页面**（Office of Undergraduate Admissions 下的具体页面或院系专属申请页）。
   - **不得只给招生办首页**——首页无法定位到题目原文，等于不可核验。
2. **题目必须为英文原文 (Verbatim Quotes)**：严禁由模型二次翻译或概括，必须逐字保留官方给出的题目、背景说明与字数限制。
3. **必须标注适用申请周期**：文书题目按申请季变动，跨周期必须全部重查。
4. **取消题目或免写判定**：若该校本年度取消小文书，必须明确标注"已核验取消"并说明核验来源。

## 3. 校园小众生态与城市暗线挖掘规范

1. **拒绝大众化通识**：禁止只罗列人人皆知的大楼、校训或泛泛的地理位置。
2. **深挖小众先锋生态**：地下音乐/艺术场馆、本地先锋节庆、圈内专属传统、标志性日常微观切片。
3. **凭证落地**：每个小众实体必须附带官方机构网站、独立艺术媒体报道或校方历史档案链接。
4. **必须核实当前运营状态**：小场馆、地下空间、独立书店**关门与迁址是常态**。
   - 引用前必须确认该实体**当前仍在运营**；
   - 若已歇业或迁址，如实标注，或改用仍在营业的替代实体；
   - **不得引用已失效域名作为证据**——域名会被转手，链接会变成完全无关的内容。

## 4. 教授任职单位核验（Why School 专项）

> [!CAUTION]
> **写 Why School 前必须确认该教授在本申请季确实属于目标院校编制。**

把外校教授当作目标院校的文书锚点，是招生官一查就能发现的硬伤。常见误区：

- 教授在目标院校**授课/客座**，但**编制在另一所学校**；
- 教授已**跳槽或荣休**，但旧页面仍在；
- 把**联合聘任 (joint appointment)** 的次要单位当作其主要单位。

核验方式：以该教授**所在院系的官方教职名录页**为准，交叉核对 ORCID 或院系新闻页。

## 5. 时效戳规范

每条外部事实必须标注 `核验日期：YYYY-MM-DD`。不同数据腐朽速度不同：

| 数据类型 | 时效窗口 | 说明 |
| :--- | :--- | :--- |
| DOI / PubMed 文献 | 永久 | 已正式出版即不变 |
| 教授任职、招生政策 | 约 180 天 | 会跳槽、会换届 |
| 文书题目、字数限制、DDL | **单申请季** | 跨周期必须全部重查 |
| 场馆、节庆、学生项目、资助 | 约 365 天 | 会歇业、会改名、会停办 |

> 把永久数据与易腐数据混排而不加区分，会让读者误以为所有信息同等新鲜。
> 一个永久 DOI 旁边放着一个三年前的资助金额，暗示两者都是当前有效——只有一个是。

---

## 6. 文书大纲去 AI 化规范

1. **禁止一切形容词与虚浮修饰**：严禁出现"心灵的减压舱"、"震撼的交响"、"灵魂的共鸣"等无实质信息的套话。
2. **纯事实与建设性指令 (Bullet Points)**：
   - 交代具体场景与事实冲突；
   - 交代具体行动与认知结论；
   - 精准对接大学导师专著、具体论文观点与实验室平台；
   - 交代具体的校园/社群落地行动。
